## What this is

The authoring repo behind my [21st.dev profile](https://21st.dev/@kedhareswer). If a piece is live on the profile, its source is here. If it isn't here, it isn't public.

- **`components/`** — copy-paste-ready React UI pieces. **17 live**, including Alice Scroll Story, Anchored Action Bar, Festivity Hero, Glass Clock, Liquid Glass Cards, Mouse Trail, Particle Animation, Scroll Book, Snow Ball Loading Spinner.
- **`library/`** — larger reusable collections published under my namespace.

This repo is the source, 21st.dev is the distribution channel. Every publish is a commit, so nothing is hand-edited downstream and any version is one `git log` away.

## Use it

**Install from 21st** — open a piece on [the profile](https://21st.dev/@kedhareswer) and run its command:

```bash
npx shadcn@latest add "https://21st.dev/r/kedhareswer/<slug>"
```

**Or copy the source** — grab `components/<slug>/` straight from this repo. Each folder is self-contained: Tailwind + one component file, no local imports to chase.

Built with React + TypeScript + Tailwind, shadcn-compatible.
